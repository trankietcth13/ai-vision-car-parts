⚡ Kiến Trúc Pre-Crawl In-Memory Screening: Lọc Trong RAM Bằng Local Model

Khi cào từ các sàn xe, 85% – 90% số ảnh là ngoại thất, nội thất hoặc bánh xe. Bằng cách stream trực tiếp ảnh thumbnail siêu nhỏ (5–15KB) qua bộ nhớ RAM io.BytesIO và phân loại bằng Local Model (CLIP / YOLO-cls), hệ thống loại bỏ triệt để ảnh rác trước khi tải ảnh Full-Resolution, tiết kiệm hơn 90% băng thông và tránh hao mòn ổ đĩa SSD.

1

Listing Harvester

Playwright / Requests quét trang chi tiết xe, lấy Hãng, Dòng xe, Năm sản xuất và mảng URL ảnh thumbnail (150–300px).

2

RAM Stream (0 Disk I/O)

Tải thumbnail 10KB trực tiếp vào bộ đệm RAM qua io.BytesIO. Tuyệt đối không ghi file rác lên đĩa SSD.

3

Local Model Inference

Đưa tensor qua CLIP ViT-B/32 hoặc YOLOv8n-cls. Tốc độ suy luận chỉ 2–5ms/ảnh GPU hoặc 20ms CPU.

4

Decision Gate (P ≥ 0.80)

Nếu P ≥ 0.80 ➔ Đưa link ảnh gốc 2K/4K vào hàng đợi tải.
Nếu P < 0.80 ➔ Xóa tensor giải phóng RAM, bỏ qua 90% ảnh rác.

5

Full-Res QC & Dedup

Tải ảnh Full-Res, lọc mờ qua Laplacian Var ≥ 100, khử trùng góc qua pHash (D_H > 4).

Mã Nguồn Mẫu: Pre-Crawl In-Memory Stream (pre_filter.py)

scripts/data_pipeline/crawlers/core/pre_filter.py Python 3.11 • PyTorch • CLIP 
import io
import requests
import torch
from PIL import Image
import cv2
import numpy as np

# Tải ảnh thumbnail trực tiếp vào RAM (không ghi đĩa SSD)
def is_engine_bay_in_memory(thumb_url, clip_model, clip_processor, threshold=0.80):
    try:
        resp = requests.get(thumb_url, timeout=3)
        if resp.status_code != 200:
            return False
        # Đọc byte stream vào RAM bằng io.BytesIO
        img = Image.open(io.BytesIO(resp.content)).convert("RGB")
    except Exception:
        return False

    prompts = [
        "a car engine bay under the open hood showing engine components",
        "car exterior, dashboard, seats, wheels, documentation"
    ]
    inputs = clip_processor(text=prompts, images=img, return_tensors="pt", padding=True)
    with torch.no_grad():
        outputs = clip_model(**inputs)
        probs = outputs.logits_per_image.softmax(dim=1)[0]
    
    # Chỉ tải Full-Res nếu xác suất khoang máy >= 0.80
    return float(probs[0]) >= threshold
