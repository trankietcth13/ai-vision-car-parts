⚡ Pre-Crawl In-Memory Screening: Filtering in RAM with a Local Model

When crawling car marketplaces, 85%–90% of images show the exterior, interior or wheels. By streaming tiny thumbnails (5–15 KB) straight into RAM via io.BytesIO and classifying them with a local model (CLIP / YOLO-cls), the system discards junk images before downloading any full-resolution file, saving over 90% of bandwidth and avoiding SSD wear.

1

Listing Harvester

Playwright / Requests scans each listing page and extracts make, model, year and the list of thumbnail URLs (150–300 px).

2

RAM Stream (0 Disk I/O)

Downloads 10 KB thumbnails directly into a RAM buffer via io.BytesIO. No junk files are ever written to the SSD.

3

Local Model Inference

Runs the tensor through CLIP ViT-B/32 or YOLOv8n-cls. Inference takes only 2–5 ms per image on GPU or 20 ms on CPU.

4

Decision Gate (P ≥ 0.80)

If P ≥ 0.80 ➔ queue the original 2K/4K image URL for download.
If P < 0.80 ➔ drop the tensor, free RAM, and skip ~90% of junk images.

5

Full-Res QC & Dedup

Downloads the full-res image, filters blur with Laplacian Var ≥ 100, and removes near-duplicate angles with pHash (D_H > 4).

Sample Code: Pre-Crawl In-Memory Stream (pre_filter.py)

scripts/data_pipeline/crawlers/core/pre_filter.py Python 3.11 • PyTorch • CLIP 
import io
import requests
import torch
from PIL import Image
import cv2
import numpy as np

# Download the thumbnail straight into RAM (no SSD writes)
def is_engine_bay_in_memory(thumb_url, clip_model, clip_processor, threshold=0.80):
    try:
        resp = requests.get(thumb_url, timeout=3)
        if resp.status_code != 200:
            return False
        # Read the byte stream into RAM with io.BytesIO
        img = Image.open(io.BytesIO(resp.content)).convert("RGB")
    except Exception:
        return False

    prompts = [
        "a car engine bay under the open hood showing engine components",
        "car exterior, dashboard, seats, wheels, documentation"
    ]
    inputs = clip_processor(text=prompts, images=img, return_tensors="pt", padding=True)
    with torch.no_grad():
        outputs = clip_model(**inputs)
        probs = outputs.logits_per_image.softmax(dim=1)[0]

    # Only download the full-res image if engine bay probability >= 0.80
    return float(probs[0]) >= threshold

✨ The Value of Before / After Image Pairs from Detailing Studios

A model trained only on showroom cars becomes biased toward glossy black plastic and clean metal. Once deployed on real customer cars in for service:

  • Before photos (AMMO NYC / Hà Thành Garage): red dust, oil stains, cobwebs, rusty bolts. They teach the model dirt invariance.
  • After photos (Chicago Auto Pros / DPRO VN): cleaned with dry ice blasting or plastic dressing spray. They keep the model from confusing glare and reflections with object edges.
